A make.fun entry: one sentence explaining the modern internet to a traveler
from the year 1800, built only from things they already know — a post office,
letters, books, pictures, lightning.

> The whole world has become one great post office, where letters, books, and pictures travel by lightning and arrive before you finish asking for them.
